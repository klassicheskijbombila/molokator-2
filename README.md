# Молокатор — MVP

Мобильное веб-приложение (PWA): молочная карта, тест «Какой ты молочный человек?» и Молочный паспорт. Есть классический и безлактозный режим.

## Публикация

Репозиторий уже настроен для GitHub Pages: файлы лежат в корне ветки `main`, входная страница — `index.html`.

Включите Pages:

1. Откройте **Settings → Pages**.
2. В **Build and deployment** выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
3. Нажмите **Save**.

Сайт будет доступен по адресу:

`https://klassicheskijbombila.github.io/molokator-2/`

## Возможности

- Выбор классического или безлактозного режима.
- 7 вопросов, 14 типов, подсчёт очков и правило ничьей.
- Молочный паспорт: тип, уровень, черты, союзник, антипод, номер.
- Share через Web Share API и копирование ссылки.
- Демо-карта Москвы на Leaflet/OpenStreetMap с фильтрами.
- Офлайн-кэш через Service Worker.
- Аналитика событий в localStorage для первого теста.

## Дисклеймер

Молокатор — развлекательный сервис. Он не даёт медицинских рекомендаций, не диагностирует непереносимость лактозы и не заменяет консультацию врача.
