# Молокатор v6 — единая сборка

Логика: app.js. Данные: data.js. Стили: style.css. Старые fixes.js, passport-v3.js, navigation-v4.js и questions.js больше не подключаются.

7 вопросов, по 7 вариантов, 14 типов в двух режимах. Один ответ — один балл соответствующему архетипу. При равенстве побеждает самый поздно выбранный из лидеров. Процент — доля ответов за победивший образ, не медицинский показатель.

Ответы и паспорт сохраняются в localStorage. Ссылка содержит паспорт во fragment URL. Сравнение: открыть чужой паспорт и пройти свой в этой же вкладке. PNG создаётся через Canvas. Оформление занимает 10 секунд без пропуска. После обновления готовый паспорт доступен на главной.

Вместо непроверенного каталога — внешний поиск на Яндекс Картах.

Проверки математической модели: python3 tests.py. Результаты: test-results.json. Браузерные проверки Safari/Chrome не выполнены. Проверить назад/вперёд, оба режима, обновление страницы, share-ссылку, PNG, офлайн после первого открытия и узкие экраны.

Нет серверного каталога, платежей, общей аналитики или динамических OG-превью. SVG-иконку для широкого PWA-релиза нужно дополнить PNG и проверить на iOS.
